Minimum Spanning Tree (Kruskal & Prim)

🕸️ Graph · Important · Medium

Worst case Kruskal O(E log E); Prim O(E log V)Priority 4/5
← All Algorithms← Union-Find (Disjoint Set Union) · Greedy Fundamentals & Activity Selection →

1 · What is it?

A minimum spanning tree connects every node of a weighted, undirected graph using exactly V−1 edges with the smallest possible total weight and no cycles. Kruskal sorts all edges by weight and keeps each one whose endpoints are in different components (checked with union-find). Prim grows a single tree outward from a start node, always swallowing the cheapest edge that leaves the tree (frontier managed by a heap). The cut property — across any partition, the lightest crossing edge is safe — proves both correct.

2 · Why, When & How to select

Why we need it

Whenever you must link everything for the least total cost — cabling, pipelining, circuit wiring, cluster merging — the MST is the exact optimum, and it is one of the few hard-looking optimisation problems with a fast, provably optimal greedy solution. MSTs also seed approximations for harder problems (travelling salesman) and define single-linkage clustering.

When it is needed

  • Connecting all sites with minimum total edge weight (networks, grids, roads).
  • Reducing redundant links while keeping the graph connected (backbone design).
  • Single-linkage clustering: cut the V−k heaviest MST edges to get k clusters.
  • A starting structure for approximating NP-hard problems such as metric TSP.

How to select it

  • Sparse graph (E ≈ V): Kruskal is simple and sorts few edges.
  • Dense graph (E ≈ V²): Prim with an adjacency matrix in O(V²) beats sorting all edges.
  • Edges arrive pre-sorted or weights are tiny integers: Kruskal runs in near-linear time.
  • Need incremental queries ('is the MST still the same after this edge changes?') — dynamic MST structures exist but are advanced.
  • Disconnected graph? No spanning tree exists — run the algorithm per component (a minimum spanning forest).

When NOT to use it

  • You need shortest PATHS, not cheapest connectivity — Dijkstra answers distances; MST minimises total weight only.
  • The graph is directed — spanning trees are undefined; use arborescences (Edmonds) instead.
  • Per-pair latency matters — an MST can make some individual paths longer than the original graph offers.
  • Edges must satisfy constraints beyond weight (capacity, degree limits) — MST does not handle side constraints.

5 · Implementation (C / C++ / Python)

#include <stdio.h>
#include <stdlib.h>

#define V 5

/* ---------- Kruskal: sort edges + union-find ---------- */
typedef struct { int u, v, w; } Edge;

int find(int parent[], int x) {
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];   /* path halving */
        x = parent[x];
    }
    return x;
}

int cmp_edges(const void *a, const void *b) {
    return ((const Edge *)a)->w - ((const Edge *)b)->w;
}

int kruskal(Edge edges[], int m, Edge mst[]) {
    int parent[V];
    for (int i = 0; i < V; i++) parent[i] = i;
    qsort(edges, m, sizeof(Edge), cmp_edges);
    int count = 0, total = 0;
    for (int i = 0; i < m && count < V - 1; i++) {
        int ru = find(parent, edges[i].u), rv = find(parent, edges[i].v);
        if (ru != rv) {
            parent[ru] = rv;             /* union joins two trees */
            mst[count++] = edges[i];
            total += edges[i].w;
        }
    }
    return total;
}

/* ---------- Prim: grow one tree, O(V^2) with arrays ---------- */
int prim(int g[V][V], int mst[V - 1][3]) {
    int in_tree[V] = {0};
    int key[V];                        /* cheapest edge into the tree */
    int from[V];
    for (int i = 0; i < V; i++) { key[i] = 1 << 30; from[i] = -1; }
    key[0] = 0;
    int total = 0, count = 0;
    for (int step = 0; step < V; step++) {
        int best = -1;
        for (int v = 0; v < V; v++)
            if (!in_tree[v] && (best == -1 || key[v] < key[best])) best = v;
        in_tree[best] = 1;
        if (from[best] != -1) {
            mst[count][0] = from[best]; mst[count][1] = best; mst[count][2] = key[best];
            total += key[best]; count++;
        }
        for (int v = 0; v < V; v++)
            if (!in_tree[v] && g[best][v] && g[best][v] < key[v]) {
                key[v] = g[best][v];
                from[v] = best;
            }
    }
    return total;
}

int main(void) {
    /* Same graph in both forms: 5 nodes, 7 weighted edges. */
    Edge edges[] = {{0,1,2},{0,2,3},{1,2,1},{1,3,4},{2,3,5},{2,4,6},{3,4,7}};
    Edge mst[V - 1];
    int total = kruskal(edges, 7, mst);
    printf("Test 1 (Kruskal) total=%d edges:", total);
    for (int i = 0; i < V - 1; i++) printf(" %d-%d(w=%d)", mst[i].u, mst[i].v, mst[i].w);
    printf("\n");

    int g[V][V] = {{0,2,3,0,0},{2,0,1,4,0},{3,1,0,5,6},{0,4,5,0,7},{0,0,6,7,0}};
    int pmst[V - 1][3];
    total = prim(g, pmst);
    printf("Test 2 (Prim) total=%d edges:", total);
    for (int i = 0; i < V - 1; i++) printf(" %d-%d(w=%d)", pmst[i][0], pmst[i][1], pmst[i][2]);
    printf("\n");
    return 0;
}

#include <algorithm>
#include <iostream>
#include <queue>
#include <tuple>
#include <vector>
using namespace std;

struct DSU {
    vector<int> parent, rank_;
    explicit DSU(int n) : parent(n), rank_(n, 0) {
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    int find(int x) {
        while (parent[x] != x) { parent[x] = parent[parent[x]]; x = parent[x]; }
        return x;
    }
    bool unite(int a, int b) {
        int ra = find(a), rb = find(b);
        if (ra == rb) return false;
        if (rank_[ra] < rank_[rb]) swap(ra, rb);
        parent[rb] = ra;
        if (rank_[ra] == rank_[rb]) rank_[ra]++;
        return true;
    }
};

/* Kruskal: O(E log E) — sort edges, union them greedily. */
vector<tuple<int,int,int>> kruskal(int n, vector<tuple<int,int,int>> edges) {
    sort(edges.begin(), edges.end(), [](const auto& a, const auto& b) { return get<2>(a) < get<2>(b); });
    DSU dsu(n);
    vector<tuple<int,int,int>> mst;
    int total = 0;
    for (auto [u, v, w] : edges) {
        if (dsu.unite(u, v)) {
            mst.push_back({u, v, w});
            total += w;
        }
    }
    cout << "Test 1 (Kruskal) total=" << total << " edges:";
    for (auto [u, v, w] : mst) cout << " " << u << "-" << v << "(w=" << w << ")";
    cout << "\n";
    return mst;
}

/* Prim: O(E log V) with a min-heap of (weight, node, parent). */
void prim(int n, const vector<vector<pair<int,int>>>& adj) {
    using T = tuple<int,int,int>;              // (weight, node, parent)
    priority_queue<T, vector<T>, greater<T>> pq;
    vector<bool> in_tree(n, false);
    vector<tuple<int,int,int>> mst;
    int total = 0;
    pq.push({0, 0, -1});
    while (!pq.empty()) {
        auto [w, u, p] = pq.top(); pq.pop();
        if (in_tree[u]) continue;
        in_tree[u] = true;
        if (p != -1) { mst.push_back({p, u, w}); total += w; }
        for (auto [v, ew] : adj[u])
            if (!in_tree[v]) pq.push({ew, v, u});
    }
    cout << "Test 2 (Prim) total=" << total << " edges:";
    for (auto [u, v, w] : mst) cout << " " << u << "-" << v << "(w=" << w << ")";
    cout << "\n";
}

int main() {
    vector<tuple<int,int,int>> edges = {{0,1,2},{0,2,3},{1,2,1},{1,3,4},{2,3,5},{2,4,6},{3,4,7}};
    kruskal(5, edges);

    vector<vector<pair<int,int>>> adj(5);
    for (auto [u, v, w] : edges) { adj[u].push_back({v, w}); adj[v].push_back({u, w}); }
    prim(5, adj);
    return 0;
}

def kruskal(n, edges):
    """Minimum spanning tree: sort edges, unite with DSU. O(E log E)."""
    parent = list(range(n))

    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]   # path halving
            x = parent[x]
        return x

    total, mst = 0, []
    for u, v, w in sorted(edges, key=lambda e: e[2]):
        ru, rv = find(u), find(v)
        if ru != rv:
            parent[ru] = rv
            mst.append((u, v, w))
            total += w
    return mst, total


def prim(n, adj):
    """Minimum spanning tree grown from node 0 with a heap. O(E log V)."""
    import heapq
    in_tree = [False] * n
    pq = [(0, 0, -1)]                     # (weight, node, parent)
    total, mst = 0, []
    while pq:
        w, u, p = heapq.heappop(pq)
        if in_tree[u]:
            continue
        in_tree[u] = True
        if p != -1:
            mst.append((p, u, w))
            total += w
        for v, ew in adj[u]:
            if not in_tree[v]:
                heapq.heappush(pq, (ew, v, u))
    return mst, total


if __name__ == "__main__":
    edges = [(0, 1, 2), (0, 2, 3), (1, 2, 1), (1, 3, 4), (2, 3, 5), (2, 4, 6), (3, 4, 7)]
    mst, total = kruskal(5, edges)
    print("Test 1 (Kruskal) total={} edges: {}".format(
        total, " ".join(f"{u}-{v}(w={w})" for u, v, w in mst)))

    adj = [[] for _ in range(5)]
    for u, v, w in edges:
        adj[u].append((v, w))
        adj[v].append((u, w))
    mst, total = prim(5, adj)
    print("Test 2 (Prim) total={} edges: {}".format(
        total, " ".join(f"{u}-{v}(w={w})" for u, v, w in mst)))

7 · Real-world applications

📌 Telecom & utility networks

Fiber, power-line, and pipeline layouts are planned as MSTs to minimise cabling cost.

📌 Circuit design

Wire-length minimisation in VLSI routing uses rectilinear MSTs (e.g. Prim/Boruvka variants).

📌 Cluster analysis

Single-linkage clustering is an MST: cut its longest edges to split groups.

📌 Approximation algorithms

The 2-approximation for metric TSP builds an MST, then shortcuts a depth-first walk of it.
